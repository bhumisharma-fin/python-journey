# Setting Up Python - Beginners Guide

## Step 1: Install Python
1. Go to https://python.org/downloads
2. Click Download Python 3.x.x
3. Install (Windows: tick "Add to PATH")
4. Check: in terminal write `python --version`

## Step 2: Install VS Code
1. https://code.visualstudio.com
2. Install Python extension inside VS Code

## Step 3: Install Libraries
```
pip install numpy pandas matplotlib openpyxl yfinance
```

## Common Errors
- ModuleNotFoundError: pip install that module
- SyntaxError: typo in code, check line number
- IndentationError: use 4 spaces, not tabs
- NameError: variable name spelled wrong
