# Practice Problems - Python Finance 💪

Try solving these yourself! Solutions in solutions/ folder.

## Level 1 - Basics

### Problem 1: Simple Budget
Create a program that:
- Takes monthly income as input
- Asks for expenses in different categories
- Shows remaining savings
- Says if savings > 20% of income or not

### Problem 2: Price List
Given a list of prices: [250, 499, 1299, 89, 3500, 750]
- Find the average price
- Find items under Rs 500
- Apply 10% discount to all items

### Problem 3: Student Grades
Dictionary: {"Bhumi": 85, "Nick": 92, "Rahul": 78}
- Find highest scorer
- Calculate class average
- Print "Pass" if marks > 60 else "Fail"

## Level 2 - Finance

### Problem 4: Loan Calculator
Build an EMI calculator that:
- Takes principal, rate, tenure as input
- Shows monthly EMI
- Shows total interest paid
- Shows amortization for first 6 months

### Problem 5: Expense Categorizer
Read a list of transactions and:
- Automatically categorize (Food, Transport, etc)
- Show category-wise total
- Find the biggest expense

### Problem 6: Investment Comparison
Compare three options for Rs 1 lakh:
- FD at 7% for 5 years
- Gold at 10% average for 5 years
- Mutual Fund at 12% for 5 years
Show final values and recommend best option

## Level 3 - Advanced

### Problem 7: Personal Finance Dashboard
Build a complete dashboard that shows:
- Monthly income vs expense trend
- Savings rate over 6 months
- Investment portfolio performance
- Net worth calculation

### Problem 8: CSV Analyzer
Download your bank statement CSV and:
- Clean the data
- Categorize all transactions
- Find top 5 spending categories
- Plot a pie chart

## Tips
- Start with Level 1
- Google is your friend!
- Break big problems into small steps
- Test with simple numbers first
