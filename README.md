## Key Finance Formulas

EMI = P * r * (1+r)^n / ((1+r)^n - 1)
Compound Interest = P * (1 + r/n)^(n*t)
SIP FV = PMT * ((1+r)^n - 1) / r * (1+r)
CAGR = (end/start)^(1/years) - 1
ROI = (gain - cost) / cost * 100
